Automate PR Reviews in GitHub Actions

Drop Prism into any repository with zero infrastructure or server hosting.

⚡ 100% Serverless Execution 🛡️ Trained Silence Guarantee 💬 Inline Comments & Diff Suggestions 🛑 Configurable Failure Gate
Step 1: Add Workflow .github/workflows/prism.yml 
name: Prism Code Review

on:
  pull_request:
    types: [opened, synchronize, reopened]

permissions:
  contents: read
  pull-requests: write
  checks: write

jobs:
  review:
    name: Autonomous Standards Review
    runs-on: ubuntu-latest
    steps:
      - name: Checkout PR Branch
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Run Prism Review
        uses: binodbishwakarama-max/codeagent@main
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          standards-file: ".prism/standards.yml"
          fail-on-severity: "high" # none | medium | high
Step 2: Add Standards .prism/standards.yml (Optional) 
version: "1.0"
standards:
  - id: "STD-SEC-01"
    title: "SQL Injection Prevention via Parameterized Queries"
    description: "Database queries must use parameterized queries. Never interpolate raw user input."
  - id: "STD-SEC-02"
    title: "Zero Plaintext Credentials or API Tokens"
    description: "Never hardcode passwords or secrets. Retrieve exclusively from environment variables."
  - id: "STD-ERR-01"
    title: "No Silent or Bare Exception Handling"
    description: "Catch specific exceptions with actionable logging. Never use bare except clauses."
